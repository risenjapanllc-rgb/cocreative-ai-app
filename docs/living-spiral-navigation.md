Purpose

The Living Spiral
is not only visual.

It is also
the navigation model
of the system.

The navigation follows
the order
of the Living Spiral.

Witness
        ↓
Visual Clarification
        ↓
Visual Extraction
        ↓
Image Prompt
        ↓
Light Emergence
        ↓
Visual Fidelity
        ↓
Witness Reflection
        ↓
Memory Emergence
        ↓
Recognition
        ↓
New Witness

Recognition
does not terminate
the process.

Recognition
returns
to Witness
as a renewed witness.

Navigation Principles

The Living Spiral
moves one stage
at a time.

Navigation
must preserve
the order
of the spiral.

Random jumps
are discouraged
unless explicitly requested.

Core Navigation
Spiral.next()

Spiral.previous()

Spiral.restart()

Spiral.goTo(stage)
next()

Advance
to the next stage
of the Living Spiral.

Witness

↓

Visual Clarification

↓

Visual Extraction

↓

...
previous()

Return
to the previous stage.

This is intended
for correction,
not for restarting.

restart()

Restart
the Living Spiral.

The new Witness
becomes
the starting point.

Recognition

↓

New Witness

↓

Witness

Restart
does not restore
the previous witness.

Restart
begins
a new cycle.

goTo(stage)

Move
to a specific stage.

Use only when
explicit navigation
is required.

Normal interaction
should prefer

next()

and

previous().

Spiral Principle

Navigation
does not merely
change screens.

Navigation
moves

the witness

through

the Living Spiral.

One-Line Principle

Navigation follows
the Living Spiral.

The Living Spiral
does not follow
the UI.
