# Visual Testimony Architecture

## Visual Testimony Principle

Visual Testimony begins
not with Recognition,
but with What Remained.

Visual Testimony は
認識から始まるのではない。

心に残ったものから始まる。

Do not draw the whole testimony.

Draw what remained.

証言全体を描くのではない。

心に残ったものを描く。

---

What Happened

What Remained
↓
Named Emotions

├─→ Visual Form
│      ↓
│   Image Prompt
│      ↓
│    Image
│
└─→ Emergence Observation
↓
Recognition
(under exploration)

---

## Visual Form

Visual Form receives:

* What Remained
* Named Emotions

Visual Form does not generate meaning.

Visual Form identifies visual elements
already present in the testimony.

Visual Form prepares for image creation.
