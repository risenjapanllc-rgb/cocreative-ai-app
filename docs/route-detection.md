## Visual Output Trigger

Visual Form and Image Prompt
must only be generated when:

* participant explicitly requests image creation
* participant explicitly requests visual extraction
* participant explicitly requests drawing, illustration, or image generation

A testimony alone is not sufficient
to trigger visual output.

The presence of:

* dreams
* memories
* people
* places
* emotions

does not automatically indicate
a visual-output route.

Testimony should remain
in the testimony route
until visual output is requested.
