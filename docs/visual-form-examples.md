# Visual Form Examples

## Example 1

What Remained:

「さあここからは一人で向かいなさい」

門

看板

Named Emotions:

信頼

希望

Visual Form:

朝の光

車の後部座席

黒いハット

長い白い髭の老紳士

こちらを見つめるまなざし

古い大きな門

古い木製の看板
