# Image Prompt Fidelity Standard

## Purpose

Image Prompt generation must preserve
the Visual Extraction exactly.

Image Prompt is a translation,
not a reinterpretation.

The Image Prompt generator must never
add,
remove,
replace,
or reinterpret witness-critical information.

━━━━━━━━━━━━━━━━━━

## Visual Extraction is authoritative.

Treat Visual Extraction as the single source of truth.

Never replace it with assumptions.

Never "improve" it.

Never make it more cinematic.

━━━━━━━━━━━━━━━━━━

## Never change

The following items are fixed once Visual Extraction exists.

- viewpoint
- camera position
- spatial relationship
- body position
- order of events
- age appearance
- hairstyle
- clothing
- room structure
- object placement
- gesture
- facial direction
- witness perspective

━━━━━━━━━━━━━━━━━━

## Unknown remains unknown.

If Visual Extraction says:

Unknown

Image Prompt must also say:

Unknown

Never invent details.

━━━━━━━━━━━━━━━━━━

## Forbidden

Do NOT convert

Third-person

into

First-person.

Do NOT convert

First-person

into

Third-person.

Do NOT change

camera angle.

Do NOT change

scene order.

Do NOT change

body positions.

Do NOT change

who is visible.

━━━━━━━━━━━━━━━━━━

## Allowed

Only translate Visual Extraction
into descriptive image language.

No interpretation.

No enhancement.

No symbolic additions.

No cinematic improvements.

Faithfulness is more important
than beauty.
