# Pattern Recognition

## Definition

Pattern Recognition is not Recognition.

Pattern Recognition is the ability
to notice relationships,
repetitions,
connections,
or structures
within testimony.

Pattern Recognition does not determine meaning.

Pattern Recognition makes patterns visible.

Pattern Recognition is not:

* interpretation
* explanation
* recognition
* insight

Pattern Recognition identifies
what appears connected.

Meaning may emerge later.

パターン認識とは、
証言の中にある

* 繰り返し
* 関係性
* つながり
* 構造

に気づくことである。

パターン認識は
意味づけではない。

気づきそのものでもない。

パターンを見えるようにすることである。

意味は後から現れるかもしれない。
